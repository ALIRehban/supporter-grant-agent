Problem

Nonprofit staff spend time manually searching policies,
supporter records and grant enquiries.

 
Information is distributed across structured CRM data
and policy documents.


Objective

Provide staff with a conversational agent that can answer
approved grant questions, retrieve supporter information
and assist with creating grant enquiries.


Users

Primary:
Internal nonprofit staff


Secondary:
Team managers


Not included:
External supporters
Anonymous users


Agent DOES
- Answer questions from approved knowledge.
- Find permitted supporter records.
- Find grant enquiries.
- Summarise enquiries.
- Gather information for new enquiries.
- Create an enquiry after confirmation.
- Escalate unsupported requests.


 
Agent DOES NOT
- Approve grants.
- Reject grants.
- Make financial decisions.
- Provide financial advice.
- Delete CRM records.
- Modify financial information.
- Reveal unauthorised information.
- Invent missing policy information.
- Perform write actions without confirmation.


Autonomy
Level: Low

Read actions:
Allowed

Write actions:
Human confirmation required

High-impact decisions:
Not permitted


Done when: the Agent Charter has a clear scope and boundaries.
